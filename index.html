AI Customer Chatbot — Live Demo

Built for Manish Innovations, an agriculture products exporter · by Vishal Kumar
👉 Try it now: click the green chat bubble in the bottom-right corner and ask something like "Do you export turmeric?" or "What certifications do you have?"

What this is

A retrieval-grounded AI chatbot that answers customer questions about products, certifications, and export process — using real business data instead of letting the model improvise. Built with FastAPI + Google Gemini, deployed live on Render, with conversation logging and an analytics dashboard behind the scenes.

Tech stack

FastAPI Google Gemini API SQLite logging REST analytics endpoint Render (deployment) Vanilla JS widget

About the business it's built for

Manish Innovations (innovationsmanish.com) is an APEDA and Spice Board of India certified agriculture products exporter based in Jamshedpur, India, dealing in spices, powders, nuts, pulses, and edible oils.
